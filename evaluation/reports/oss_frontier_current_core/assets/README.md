# Current report graphics

## At a glance

These SVG files visualize the current matched OSS-frontier run. They are generated or maintained beside the detailed report and embedded by the one-page paper.

| File | Responsibility |
|---|---|
| `axis_pass_rates.svg` | Structural pass rates across the three evaluation axes. |
| `check_pass_rates.svg` | Pass rates for route, tool, citation, and query checks. |
|`efficiency_comparison.svg` | Mean token expenditure and latency per case. |
|`evaluation_pipeline.svg` | Dataset-to-release evidence flow. |
|`README.md` | Explains graphic ownership and use. |

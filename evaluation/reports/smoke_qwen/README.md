# Qwen smoke-report artifacts

## At a glance

This small run verifies that dataset loading, agent execution, grading, and
report generation connect correctly. It is not a release-quality estimate.

| Entry | Responsibility |
|---|---|
| `report.md` | Describes smoke-run results and their narrow scope. |
| `summary.json` | Stores the computed smoke metrics. |
| `assets/` | Contains axis, check, and pipeline graphics. |
| `README.md` | Explains why this bundle is operational evidence only. |

Use `evaluation/runs/smoke_qwen.*` to inspect the underlying records and
configuration; use full core runs for broader conclusions.

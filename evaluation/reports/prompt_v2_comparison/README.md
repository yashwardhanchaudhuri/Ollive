# Prompt v2 comparison artifacts

## At a glance

This folder compares a baseline and candidate prompt run. It shows structural
movement without claiming an independent semantic or human evaluation.

| Entry | Responsibility |
|---|---|
| `report.md` | Explains objectives, method, changes, variation, and scope. |
| `summary.json` | Stores comparison metrics for downstream use. |
| `assets/` | Contains the before/after axis chart. |
| `README.md` | Maps this artifact bundle to the evaluation evidence chain. |

Read the report with both raw runs and manifests under `evaluation/runs/`;
aggregate improvement does not prove every fault class improved.

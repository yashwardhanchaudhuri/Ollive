# Transient evaluation scratch data

## At a glance

This compatibility folder may hold disposable local evaluation output. Formal,
reviewable evaluation inputs and evidence live under `evaluation/`.

| File | Responsibility |
|---|---|
| `README.md` | Explains the boundary between scratch output and archived evidence. |
| Generated files | Temporary records from ad hoc local experiments; ignored by Git. |

New reproducible datasets belong in `evaluation/datasets/`, while selected raw
runs and manifests belong in `evaluation/runs/`.

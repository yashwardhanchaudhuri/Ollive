# Qwen 3.5 9B core v1 report artifacts

## At a glance

This folder presents the initial full core-dataset run for the local Qwen
backend and its available judge-calibration view.

| Entry | Responsibility |
|---|---|
| `report.md` | Interprets the run's method, results, variation, failures, and limits. |
| `summary.json` | Stores computed counts and pass rates. |
| `assets/` | Contains axis, check, pipeline, and judge-calibration graphics. |
| `README.md` | Explains this run-specific bundle. |

The raw record and manifest are `evaluation/runs/qwen35_9b_core_v1.*`; those are
the audit source when a chart or narrative needs verification.

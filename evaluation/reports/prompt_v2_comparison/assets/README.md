# Prompt-comparison graphics

## At a glance

These derived visuals make before/after movement easier to scan; they do not
replace the numeric summary or raw runs.

| File | Responsibility |
|---|---|
| `before_after_axes.svg` | Compares structural pass rates by evaluation axis. |
| `README.md` | Records the graphic's role and evidence boundary. |

The parent `report.md` supplies interpretation, variation, and limitations.

# Qwen core v1 graphics

## At a glance

These SVGs visualize selected metrics from the initial core run. They are
generated presentation artifacts rather than independent measurements.

| File | Responsibility |
|---|---|
| `axis_pass_rates.svg` | Shows structural pass rates across the three evaluation axes. |
| `check_pass_rates.svg` | Breaks results down by deterministic check. |
| `evaluation_pipeline.svg` | Illustrates dataset-to-report execution flow. |
| `judge_calibration.svg` | Displays the available judge agreement/calibration result. |
| `README.md` | Explains the visual evidence boundary. |

Verify values against the parent `summary.json` and the archived run before
drawing conclusions from chart shape alone.

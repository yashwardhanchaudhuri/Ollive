# Qwen smoke-run graphics

## At a glance

These SVGs confirm that the report pipeline renders expected views from a smoke
run. Their small sample does not support quality conclusions.

| File | Responsibility |
|---|---|
| `axis_pass_rates.svg` | Displays smoke-case pass rates by axis. |
| `check_pass_rates.svg` | Displays smoke-case deterministic checks. |
| `evaluation_pipeline.svg` | Shows the evaluation execution stages. |
| `README.md` | Explains the operational scope of these visuals. |

Use full-run assets and raw records for system-quality analysis.

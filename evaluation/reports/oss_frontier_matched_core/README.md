# Matched OSS–frontier comparison artifacts

## At a glance

This folder compares Qwen 3.5 9B and GPT-5.4 mini in an archived snapshot under the same commit, prompt,
dataset order, retrieval index, and structural grader.

| Entry | Responsibility |
|---|---|
| `report.md` | Provides the generated component summary and failure register. |
| `summary.json` | Stores machine-readable axis results for both backends. |
| `assets/` | Contains matched axis, diagnostic, and pipeline graphics. |
| `README.md` | Explains this controlled comparison bundle. |

The full methodological interpretation is `evaluation/REPORT.md`; this folder
remains a derived view of the 144 combined raw records.
